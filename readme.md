# Clone-Spotify

A project that recreates the look and feel of **Spotify** using HTML, CSS and JavaScript.

---

## 🚀 About  
This is a front-end clone of the popular music streaming platform Spotify. The goal is to mimic the UI/UX elements and provide a working prototype of playing tracks, switching songs, and a visual design similar to the original.

---

## 🧩 Features  
- Responsive layout using HTML + CSS (including Flexbox or Grid).  
- JavaScript logic for playing audio tracks, switching between songs, and visualizing progress.  
- A clean UI with playlist / cover art / controls: play/pause, next/previous.  
- Sample audio files included to demonstrate functionality (e.g., mp3 files).  
- Cover art images, background image, UI graphics for immersive experience.
